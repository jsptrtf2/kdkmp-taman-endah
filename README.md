# KDKMP Desa Taman Endah — v1.0

Struktur:
- index.html  : struktur dan konten halaman
- style.css   : seluruh styling
- script.js   : seluruh JavaScript/interaksi
- assets/     : aset gambar yang berhasil dipisahkan dari Base64
- foto/       : tempat foto pengurus/kegiatan

Catatan:
- Desain dan konten utama dipertahankan dari file sumber.
- CSS/JS inline dipindahkan ke file terpisah.
- Data gambar Base64 yang aman untuk dipisahkan dipindahkan ke assets/.
- File foto yang direferensikan sebagai foto/... tetap menggunakan struktur path tersebut.
